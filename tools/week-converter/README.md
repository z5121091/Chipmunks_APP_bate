# 生产周次转换工具

这是从 ERP 同步助手中独立出来的 Windows 桌面工具。它不启动同步服务、不占用端口、不显示托盘图标，也不会常驻后台。

## 发给别人使用

只需要发送 `dist\生产周次转换工具.exe`。对方第一次双击后，程序会自动复制到当前用户的本地应用目录，并在桌面创建“生产周次转换工具”快捷方式，全程不需要管理员权限。原始接收文件随后可以删除。

## 使用

1. 双击桌面的“生产周次转换工具”。
2. 输入 `2601`、`2602S`、`202601` 或 `2026-W01` 等生产周次。
3. 点击“转换”或按回车，查看该周的周一至周日。
4. 点击“复制日期”复制周一日期。
5. 点击窗口右上角关闭按钮后，程序立即退出。

## 重新打包

双击 `build.bat`。生成文件位于 `dist\生产周次转换工具.exe`，构建完成后会自动更新当前用户桌面的快捷方式。
