# 标签 OCR 试验

这是一份独立的 Android 测试应用。包名为 `com.chipmunks.ocrlab`，最低 Android 6.0，测试对象包括 D6（Android 13）。APK 使用本目录生成的测试证书，安装后在桌面显示「标签OCR试验」。

## 在 PDA 上测试

1. 将 `artifacts/Chipmunks-OCR-Lab.apk` 复制到 PDA 并安装。
2. 打开应用，点「拍照」进入取景。让一张标签尽量占满画面，再按「拍照」快门，应用会自动识别并显示原图。也可点「选图」导入已有照片，或点「识别样张」轮流测试内置样张 A、B。
3. 识别完成后，直接点原图上的文字，点选的位置才会高亮。再点「设为字段」，选择型号、数量等类型。可以点选多处文字合并为一个字段。再次为同一字段赋值会替换该字段。
4. 用样张 A 指定字段并点「保存模板」，再识别样张 B、点「应用模板」，核对是否提取了 B 的型号、批次和数量。当前只保存一个模板，适用于版式与构图相近的图片。
5. 「查看识别原文」展示模型输出，「复制结果」复制耗时、字段候选和原文，便于记录实测。

试验版使用 APK 内置的 ML Kit 中文与字母数字识别模型。支持静态照片逐张处理。优先用对焦清楚、文字占比高、反光少的照片测试。相机实拍与相册原图可以分别记录结果。

模板只保存字段、定位和已识别的固定前缀。换图后按相对位置重新提取。版式、构图差别较大时需要重新点选。图片、结果和模板都在独立应用内处理。该应用用于验证，不提供作业入账、打印或 ERP 连接。

## 自行构建

安装 JDK 17、Android SDK Platform 36 和 Build-Tools 36.0.0。双击「构建测试APK.cmd」，或在该目录运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build-apk.ps1
```

首次构建需要下载 Gradle 依赖。脚本生成并复用 `.keys/ocr-lab-test.jks`，验证 APK 签名后输出 `artifacts/Chipmunks-OCR-Lab.apk`。如需覆盖安装自己重新打包的试验版，请保留本目录的测试签名文件。
