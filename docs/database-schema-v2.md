# 掌上仓库新版数据库

新版数据库文件为 `palm_warehouse_v2.db`，与旧版 `warehouse.db` 完全分离。
应用不会自动导入、转换或删除旧版数据库；旧数据库只作为历史备份保留。

## 数据表

| 表名 | 用途 |
| --- | --- |
| 系统配置 | 数据库版本、安装标识和最近30天导出计数 |
| 出库单 | 出库单号、客户和仓库信息 |
| 出库明细 | 扫码出库物料明细 |
| 拆包记录 | 拆包后的发货、剩余标签记录 |
| 扫码解析规则 | 二维码解析规则和识别条件 |
| 规则占位字段 | 用于接收无需保存或导出的二维码字段 |
| 仓库 | 仓库、默认仓库和显示顺序 |
| 物料绑定 | 型号、版本号与ERP存货编码绑定 |
| 入库记录 | 采购入库扫码记录 |
| 盘点记录 | 整包、拆包盘点记录 |
| 删除回收站 | 出库单、出库明细、拆包记录和仓库的90天删除快照 |

字段名继续使用英文，保持TypeScript类型、Excel导出和同步助手接口稳定。

## 已移除结构

- `print_history`：没有业务页面使用。
- `inbound_summary`：可以由入库记录实时汇总，不再重复保存。
- 四张 `deleted_*_archive`：合并为一张“删除回收站”。
- 旧数据库迁移不会在新版数据库初始化流程中执行。

## 备份与恢复

- 自动数据库备份只读取 `palm_warehouse_v2.db`。
- 手动导出的新版数据库可以恢复到新版应用。
- 旧版 `warehouse.db` 不兼容新版恢复入口，需使用旧版应用单独查看。
