# 扣子完整整合包说明（2026-07-11）

本压缩包是当前项目的完整源码整合版，已包含此前扫码出库、扫码入库、库存查询、设置、ERP 对接、首页与本轮修复。上传时应保持压缩包中的目录结构，旧的增量修复包不再需要逐个覆盖。

## 本轮重点

- 扫码错误增加短语音提示，并修正“新订单 / 切换订单”的判断。
- 修正拆包和保存异常后的扫码输入框回焦。
- ERP 代理使用按接口区分的短缓存，并支持人工刷新绕过缓存。
- 前后端统一传递 `X-Erp-Account-Key`，为无锡笃能和上海花栗鼠隔离路由。
- 后端目标地址、账套归属和前端启用状态均改为环境或配置文件控制。
- 已从客户端源码移除 NAS/WebDAV 密码；需要认证时由云构建环境设置 `UPDATE_SERVER_URL`。
- 首页调整为出入库大入口、其余功能两列入口，并保留仅首页底部导航。

## 当前账套状态

- `wuxi-duneng`：无锡笃能，已启用，3 位单据序号。
- `shanghai-chipmunk`：上海花栗鼠，默认未启用，2 位单据序号。

上海账套正式接入时，需要配置其独立后端地址、畅捷通凭证和状态目录，再将 `EXPO_PUBLIC_ERP_SHANGHAI_CHIPMUNK_ENABLED` 设为 `true`。

## 安全与上传

- 压缩包不包含 `server/.env`、根目录 `.env.local`、openToken、AppSecret 或 `sync-data`。
- `server/erp-proxy.config.json` 只含测试后端地址，不含密钥；迁移时修改此配置或对应环境变量即可。
- 本轮按要求只做静态代码审核和打包，没有执行编译、Expo、Metro、APK 构建或线上部署。

详细审核见 `docs/code-audit-2026-07-11.md`，迁移说明见 `docs/erp-multi-account-migration.md`。
