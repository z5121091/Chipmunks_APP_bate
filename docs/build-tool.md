# 掌上仓库构建工具

项目根目录双击 `掌上仓库构建工具.exe`。顶部选择 **APK** 或 **同步助手**，再点击开始构建。独立 CMD 构建入口和窗口内的备用 CMD 按钮已移除。

## 构建与环境

- 检查环境：只检查所选目标，不生成安装包或 EXE。
- 准备环境：复用已有环境；缺少时沿用项目工具缓存准备。Android SDK 许可在可见窗口由用户阅读和确认，不自动代答。
- 开始构建：阶段、运行时间与日志在窗口显示；最小化、选择日志、切换其他程序不阻塞后台读流。
- 关闭窗口：正在运行时可选择继续后台运行；托盘或再次双击工具恢复同一任务。
- 停止任务：只终止本次构建的进程组。一个窗口一次只运行一个任务，构建中不能切换目标或修改签名。
- 文件夹按钮只指向本次成功生成的文件。失败或切换目标后会清掉上次的成功入口。

APK 继续使用现有 ARM64 发布流程和校验，输出在 `dist/apk`，附 SHA256 和校验记录。同步助手只发布 `scripts/dist/掌上仓库ERP版同步助手.exe`，重复构建更新同一个文件，旁边附 SHA256 和 PE/版本校验记录。临时文件和替换备份放在独立的构建临时目录中。若旧 EXE 被占用，构建明确失败并提示先正常退出同步助手，不另生成第二个 EXE；发布失败时恢复已替换的校验文件。发布文件的短暂收尾阶段会延后停止请求，避免 EXE 与校验文件只替换一半。构建工具以本次任务标识和实际 SHA256 确认交付，不会启动或结束同步助手，也不会清理其业务数据。

## 发布签名管理

点击“签名管理”，可以：

1. **导入原发布签名**：读取项目 `android-build.local` 关联的原配置，验证证书并复制到本机加密存储。原证书与配置文件保留。
2. **选择签名文件**：支持 PKCS#12 `.p12` / `.pfx`，填写原密码和密钥别名。不会创建新证书。
3. **导出加密备份**：选择 `.cwsign` 文件，设置并确认自己的备份密码（至少8个字符）。
4. **从备份恢复**：在新电脑选择 `.cwsign` 并输入密码，由新 Windows 账户重新加密保存；本机托管文件损坏且原配置也不可读时，先展示备份指纹并要求明确确认。

本机托管文件在 `%LOCALAPPDATA%\ChipmunksBuildTools\signing`，绑定当前 Windows 用户。不能直接复制这个 `.dat` 到新电脑使用，换机请导出、恢复便携加密备份。备份文件仅包含发布签名和签名参数，不包含源码、NAS 更新配置、数据库或构建环境；NAS 配置仍按 `android-build.local.updateServerFile` 提供。

托管数据存在但损坏时，构建会明确失败，不会悄悄切换到其他证书。导入或恢复遇到不同发布证书也会拦截。请单独保管备份密码；工具没有找回密码功能。构建时仅在当前用户可访问的临时目录落地密码保护的 PKCS#12 文件，正常结束及工具取消后清理，不写明文密码文件。

## 日志与迁移

- APK 完整窗口日志：`logs/android-build/gui`。
- 同步助手完整窗口日志：`logs/sync-build/gui`。
- 显示区会省略较早日志，完整日志仍在磁盘。HTTP(S)地址中的用户名/密码会脱敏，终端颜色控制符不会混入显示。
- 更换电脑仍需完整项目、`android-build.local`、NAS 私密配置及加密签名备份，并调整本机路径。图形工具本身使用 Windows .NET Framework 4.8 / WinForms，不需要 Python 才能打开；同步助手打包需要的 Python 由环境检查准备。
- 电脑须保持运行，睡眠可能暂停任务，关机、退出登录或强制结束工具会中止任务。

## 从源码生成图形工具

在项目根目录执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build-apk-builder.ps1
```

它使用系统 C#5 编译器和 WinForms，生成 `掌上仓库构建工具.exe`，先完整编译再原子替换。请先退出正在运行的构建工具。它只生成这个图形程序，不自动构建 APK 或同步助手，不增加任何版本号。
