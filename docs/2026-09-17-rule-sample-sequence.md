# 扫码样本连续字段分配

## 原因与修复

- 原实现只展示候选分隔符，不会自动应用；未确认时仍使用默认的 /，例如分号样本会显示为一段。
- 原字段选择器每选完一项即关闭，没有连续分配流程。虽然拆分后的各段原本均有独立选择入口，但操作不连贯。
- 增加“拆分并逐段分配”：先由用户确认候选分隔符，再连续为每段分配字段；不猜测字段业务含义。
- 每步显示当前段原文及第几段/总段数，选择后自动进入下一段，完成最后一段后返回整体预览。
- 可返回上一段，也可中途关闭后在预览中单独修改第二、第三等任意段。已选择的结果保留，未分配的位置沿用自动忽略逻辑。
- 同一个标准字段不重复分配，忽略段可以重复；保留旧规则升级兼容和忽略段内部编号。
- 打开选择器时收起软键盘；从确认分隔符到逐段选择复用同一个弹窗，避免连续关闭/打开原生弹窗；切段后选项滚动位置归顶。
- 分隔符未拆出至少两段、结束符配置无效或超过128段时，不进入无法操作的字段分配流程。手动配置的分隔符也会纳入候选。
