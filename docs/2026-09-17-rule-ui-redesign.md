# 解析规则界面重整

## 本轮调整

- 主页面保留规则名称、扫码样本、连续逐段分配和拆分结果。
- 分隔符与结束符、手动字段顺序、字段前缀、识别条件分别进入二级页面。入口显示当前设置摘要。
- 二级页面“完成”返回主页面，不单独写数据库；主页面“保存”统一保存。返回时保留样本和未保存的设置。
- Android 返回键在二级页面先返回主页面，避免误关整个编辑器。
- 隐藏字符和完整诊断信息收进“解析诊断”，主页面仅保留简要结果。
- 使用现有 Typography 和主题颜色，统一输入框、图标、行间距及触控区域，移除大阴影和冗余布局。
- 新建规则也可以设置字段前缀；移除字段时清理对应前缀，字段移动仍同步调整条件位置。
- 不改变解析引擎、结束符处理、旧规则升级及忽略段兼容逻辑。
- 更新使用说明中对应的操作路径。
