# 掌上仓库第二轮代码审查

日期：2026-07-11

## 审查方式

- 静态阅读前端、后端、SQLite、ERP 代理、配置备份和电脑同步助手代码。
- 检查设置页每个子选项的加载、保存、恢复、异常和重复操作状态。
- 按要求未启动 Expo、Metro、APK 构建、TypeScript 编译或 Python 编译。
- 只执行了差异空白检查、冲突标记检查和硬编码地址检索。

## 业务与前后端修复

1. 入库草稿按仓库和 ERP 单号隔离；旧草稿缺少单号或单号不一致时不再自动迁移，避免串单。
2. 入库草稿保存和清空改为同一条串行写队列，避免较早的异步写入晚到后让已清空草稿重新出现。
3. 清空入库扫码记录失败时不再假装成功，并保留 ERP 带出的供应商。
4. 采购入库详情始终使用列表项自己的账套；切换账套会废弃旧详情请求，避免旧响应覆盖新账套。
5. 库存查询开始新请求和请求失败时会清空旧结果；规格型号允许显示两行。
6. 出库重新扫描已缓存单据时优先使用本机缓存，手动刷新仍会绕过两层缓存；后台恢复旧订单不会覆盖用户刚切换的新订单。
7. ERP 存货编码比较统一为不区分大小写，避免绑定编码与 ERP 返回大小写不同而被误判“不在本单”。
8. 前端后端请求增加完整响应读取超时；强制刷新请求不再与普通缓存请求合并。
9. ERP 缓存下沉到正式 ERP 后端核心层，正式 APK 直连时也能复用缓存，不再只依赖扣子中转缓存。
10. 后端代理请求体限制为 5 MB；显式 `CHANJET_PROXY_MODE=false` 会真正关闭代理模式。
11. Chanjet 状态主文件损坏时保留最后有效备份，不再用损坏文件覆盖 `.bak`。
12. OAuth 自动回调换取的 Token 改为后端内部保存，公网回调不再直接返回 Token；手动换取和刷新也会更新状态文件。
13. NAS WebDAV 建目录和文件查重请求增加 12 秒超时，网络异常时不再让备份或更新流程长时间停住。

## 同步助手本轮已完成

- 健康检查加入固定 `serviceId` 和 API 版本，APP 不会把任意 HTTP 200 服务误认为同步助手。
- 保存目录和端口可通过 `PALM_WAREHOUSE_SYNC_DIR`、`PALM_WAREHOUSE_SYNC_PORT` 迁移，无需改源码。
- 改善本机 IPv4 选择；无 D 盘时回退到用户文档目录。
- 上传限制为 25 MB，校验 XLSX 头，文件名和后缀经过清理。
- 每个请求使用独立临时文件，并用全局写锁避免多个导出同时破坏工作簿。
- 序列号写入增加 Excel 公式注入保护；响应明确返回文件名。

## 保留风险

1. 为兼容现有扣子 APK，ERP 业务查询路由仍未强制客户端密钥；管理路由继续使用独立管理密钥。正式公网部署前应结合反向代理、来源限制或设备令牌收紧。
2. 同步助手仍监听局域网 `0.0.0.0` 且允许跨域，没有设备配对令牌。现在适合可信内网，不适合直接暴露公网。
3. 在线更新目前依赖 HTTPS 和 Android 安装校验，但 `version.json` 尚未提供 APK SHA-256；更新源被替换时缺少应用层完整性校验。
4. 采购入库列表仍只取前 100 条。根据既定要求，本轮保持不变。
5. 本轮按要求未编译或运行，因此运行时兼容性仍需在本地 Web、PDA 或扣子 APK 中做一次冒烟验证。

## 同步助手下一步建议

1. **扫码配对令牌**：助手首次启动生成随机令牌和二维码，APP 扫码保存，后续上传携带 `X-Sync-Key`。这是下一步优先级最高的安全改进，需要 APP 与助手同时升级。
2. **自动发现电脑**：使用 mDNS 或局域网 UDP 广播，让 APP 自动列出“电脑名 + IP + 版本”，减少手填 IP 和多网卡选错的问题。
3. **传输任务与去重**：每次同步携带请求 ID 和文件哈希；助手记录最近任务，网络重试时返回原结果而不是重复生成文件。
4. **原子落盘与占用处理**：先保存到同目录临时文件，再原子替换；目标 Excel 被打开占用时自动生成带序号的新文件并明确提示。
5. **托盘诊断页**：可视化修改保存目录和端口，显示当前网卡、最近接收、失败原因、Windows 防火墙状态，并提供“一键复制连接信息”。
6. **版本协商与升级提醒**：APP 读取助手 API 版本，版本过旧时明确提示升级；助手可检查新版本但不静默安装。
