# 掌上仓库可视化标签助手

这是原同步助手的独立实验版，不会覆盖 `scripts/label_sync_server.py`。

## 已支持

- 标签纸张尺寸、DPI 和每条记录的打印份数。
- 文字、Code 128 条码、QR Code 和图片元素。
- 鼠标拖动元素，使用选中框八个控制点改变大小；条码和二维码自动吸附到打印机真实点阵。
- 文字字体、字号、加粗和左/中/右对齐。
- 元素可选“固定内容”或“关联字段”，关联字段允许手工输入 Excel 表头和预览示例值。
- 条码高度和密度。
- 二维码大小、容错等级、掩码、自定义分隔符、多个动态/固定内容段。
- 图片保持原始宽高比，预览和打印使用相同的单色转换结果。
- 模板保存、另存为、导入、导出、删除、恢复 APM 默认模板和测试打印。
- 自动记忆打印机与窗口布局，切换模板或退出前提示保存未提交修改。
- 同步服务直接使用当前活动模板；模板无效时停止打印并返回错误，避免误用其他版式。

## 开发环境启动

```powershell
cd D:\掌上仓库-SQL\scripts\visual-label-assistant
python -m pip install -r requirements.txt
python app.py --designer
```

也可双击 `start-designer.bat`。不带 `--designer` 参数时会启动这一份独立同步服务。

## 打包为 EXE

直接双击 `build.bat`。脚本会自动安装依赖并打包，首次需要等待几分钟。成功后会自动打开 `dist` 目录，生成的文件是：

```text
dist\掌上仓库可视化同步助手.exe
```

这是新的独立 EXE，不会替换原来的 `掌上仓库同步服务.exe`。

## 模板保存位置

默认保存在 `D:\数据同步\label-templates`，可用环境变量 `PALM_WAREHOUSE_TEMPLATE_DIR` 更改。

## 二维码内容段格式

在属性面板中每行写一段：

```text
字段:model
字段:batch
固定:APM
字段:quantity
```

分隔符可设为 `/`、`|`、`;` 或任意文字。空字段默认会跳过，不会产生连续分隔符。

## 后续阶段

暂不做多模板自动匹配。当实际模板种类明确后，再在模板中加入型号、客户、解析规则等匹配条件。
