# 掌上仓库 ERP版同步助手说明

`label_sync_server.py` 是掌上仓库 APP 的电脑端同步助手。手机端把 Excel 数据发送到本机服务后，同步助手会把文件保存到电脑目录，便于后续打印、归档或导入其他系统。

## 运行方式

### 直接运行

```bash
pip install cherrypy openpyxl pystray Pillow pywin32 pyinstaller
python label_sync_server.py
```

### 打包成 EXE

推荐使用仓库中的打包脚本：

```bat
build.bat
```

打包后双击 `dist\掌上仓库ERP版同步助手.exe` 即可运行。运行后程序会以“掌上仓库 ERP版同步助手”常驻系统托盘，便于和旧版同步服务区分。

## 拆包标签自动打印

扫码出库确认拆包后，APP 会先把原有 `标签打印.xlsx` 保存到同步目录，再向同步助手提交一次明确的原生打印任务。同步助手会按每条标签记录打印两份：发货标签两份、剩余标签两份。

默认打印队列名称为 `TSC TTP-244 Pro`。如果公司电脑中的实际打印队列名称不同，请在启动同步助手前设置环境变量：

```bat
set PALM_WAREHOUSE_PRINTER_NAME=你的实际打印机名称
```

设置后重新启动同步助手。若自动打印失败，日志和托盘通知会显示当前 Windows 可用的打印机名称，便于核对。

- PDA 成功时不显示额外的打印任务提示；打印失败时才会提示。
- 设置中的“同步订单标签”仍然只导出 Excel，不会触发打印。
- 每次拆包使用唯一任务标识；网络超时或重复提交不会重复出纸。
- ERP 版自动打印使用 `native_tsc_supplier_v2` 协议；旧同步助手不支持该协议，因此不会误用旧版“所有拆包都打印”的逻辑。
- 标签 Excel 会携带物料绑定中的“供应商”字段，并按供应商全称选择模板：
  - `珠海极海半导体有限公司`：使用现有“极海”模板，保留 Geehy Logo。
  - `珠海领芯科技有限公司`：使用“珠海领芯”模板，版式与极海一致但不显示 Logo。
  - `珠海博雅科技股份有限公司`：使用“珠海博雅”模板，显示 BYT Logo、BOYA MICROELECTRONICS 品牌栏、六行物料信息、合规标识和二维码。
  - 其他供应商或未填写供应商：仍保存 `标签打印.xlsx`，但不自动打印，后续可手动打印。
- 原生标签二维码使用 `/` 分隔。极海和领芯按固定八字段写入：型号、批次、封装、版本或 APM 料号、数量、生产周次、追溯码、箱号。珠海博雅按固定六字段写入：型号、封装、数量、批次、生产日期、箱号。
- 标签文字统一使用 Arial 8 磅；`COO:CN`、`RoHS`、`MSL3` 使用 Arial 粗体 8 磅。
- Geehy 与珠海博雅品牌区域分别使用 `assets/geehy-logo.png` 和 `assets/boya-logo.png`；构建 EXE 时会自动打包两个资源。
- 二维码使用 `0.75 mm` 单元、自动版本、自动编码、L 级纠错，以及 TSC 官方手机示例使用的 `Model 2 / S7`；当前八码内容均为 ASCII，发送字节与 Shift-JIS 932 完全一致。`COO:CN` 距当前 33 模块二维码底边 2 点（约 `0.25 mm`），三行文字和 `5 x 5` 毫米的 `assets/pb-logo.png` 图标均与二维码第 773 点的右边缘对齐，而不是与纸张边缘对齐。
- 按 BarTender 参数换算：型号、`BOX ID` 的 Code 128 使用 1 点宽（约 `0.13 mm`）；`LOT NO`、`PKG`、`P/N`、`QTY`、`DATE`、`T/C` 使用 2 点宽（约 `0.25 mm`）；全部高度为 32 点（`4.0 mm`）。
- 一维码高度为 4.0 毫米并关闭条码下方的可读字符；二维码单元尺寸为约 0.75 毫米。
- 同步助手会在电脑端用 Windows Arial 生成小型黑白文字层，再配合打印机原生条码输出；不会向打印机安装、删除或下载字体，避免打印机进入错误状态。
- 同步助手不会切换热敏或热转印模式；TSC TTP-244 Pro 会继续沿用打印机当前的碳带热转印设置。
- 12 位纯数字的 APM 料号会打印在 `P/N`，不会再误显示为 `VER`；真正的短版本号（例如 `B1`）仍显示在 `VER`。

## 服务地址

默认端口：`8080`

健康检查地址：

```text
http://电脑IP:8080/health
```

手机端在“设置 -> 电脑同步”里填写电脑 IP 和端口后，可以测试连接。

## 数据保存目录

默认保存目录：

```text
D:\数据同步
```

同步助手会自动创建目录。手机端同步成功后，会返回实际保存的文件名。

## 当前接口

| 接口 | 用途 |
| --- | --- |
| `/health` | 检查同步助手是否在线 |
| `/inbound` | 接收入库单 Excel |
| `/outbound` | 接收出库单 Excel |
| `/inventory` | 接收盘点单或盘点拆包标签 Excel |
| `/labels` | 接收订单拆包标签 Excel |
| `/materials` | 接收物料绑定 Excel |

## 文件命名规则

同步助手支持两种命名方式：

- `file_name`：手机端传入精确文件名时，电脑端按该名称保存。
- `name_suffix`：手机端只传入后缀时，电脑端按业务类型拼接文件名。

例如：

```text
入库单_无锡总仓_20260518_02.xlsx
出库单_无锡总仓_20260518_01.xlsx
盘点单_无锡总仓_完整数据_20260518_01.xlsx
盘点拆包标签_20260518.xlsx
订单标签_20260518.xlsx
```

如果手机端传入 `file_name`，以手机端文件名为准；这是当前 APP 重新同步历史单据时使用的主要方式。

## Excel 处理说明

- 同步助手接收的是手机端生成的 `.xlsx` 文件。
- 入库、盘点等多 Sheet 文件会保留原 Sheet 结构。
- 同步助手会补充基础字体、边框、居中和列宽。
- 为避免历史数据很大时卡顿，样式处理只采样前面部分行。

## 周次转换工具

托盘工具中包含芯片周次转换功能，支持常见周次写法，例如：

```text
2601
2602S
202601
2026-W01
```

转换结果以周一为准，适合把芯片周次换算为生产日期。

## 常见问题

### 手机连接失败

1. 确认电脑和手机在同一局域网。
2. 确认同步助手正在运行，托盘图标没有退出。
3. 在电脑浏览器打开 `http://localhost:8080/health`，确认服务正常。
4. 检查 Windows 防火墙是否放行 8080 端口。

### 同步失败但服务在线

1. 检查 `D:\数据同步` 是否有写入权限。
2. 确认目标 Excel 文件没有被 WPS/Excel 正在占用。
3. 查看同步助手同目录下的 `日志记录.log`。
